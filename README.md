# 🛒 Retail Store Management System

A database management project built using SQL that simulates the operations of a retail store. The project demonstrates relational database design, data management, and business analysis using SQL queries.

---

## 📌 Project Overview

This project implements a Retail Store Management System that stores and manages retail business data efficiently. It includes database creation, table relationships, data insertion, and SQL queries to analyze sales, customers, inventory, and overall business performance.

---

## ❓ Problem Statement

Retail businesses handle large amounts of customer, product, inventory, and sales data. Without a well-structured database, managing and analyzing this information becomes challenging. This project solves that problem by designing a normalized SQL database capable of storing and retrieving business data efficiently.

---

## 🎯 Objectives

- Design a relational retail database
- Manage customer, product, supplier, and order data
- Maintain relationships using Primary and Foreign Keys
- Perform business analysis using SQL queries
- Generate meaningful business insights
- Practice real-world SQL concepts

---

## 🧠 What is a Retail Store Management System?

A Retail Store Management System is a database that helps businesses organize and manage their daily operations.

It includes:

- 👥 Customer Management
- 📦 Product Management
- 🏭 Supplier Management
- 🛒 Order Management
- 📦 Inventory Tracking
- 👨‍💼 Employee Management
- 💰 Sales Analysis

The database enables efficient storage, retrieval, and analysis of retail business data.
